# Learning Journey 📚

## App Name & Purpose

**Learning Journey** is a learning progress tracking app designed to help users stay consistent and motivated while achieving their learning goals. It allows users to track their daily learning activities, maintain their streaks, and monitor their progress over time.

## Main Features

- **Set Learning Goals:** Users can set their learning goals and choose a learning duration (Weekly, Monthly, or Yearly).
- **Track Daily Progress:** Users can mark each day as "Learned" to record their learning activity.
- **Freeze Days:** Users can use Freeze days to protect their learning streak when they cannot study.
- **Activity Tracking:** Users can view their weekly learning activity and track their progress.
- **Calendar View:** Users can view their learning history through a calendar that displays Learned and Freeze days.
- **Edit Learning Goals:** Users can update their learning goals and choose a new duration.
- **Freeze Limits:** The app provides different Freeze limits depending on the selected duration:
  - Weekly: 2 Freezes
  - Monthly: 8 Freezes
  - Yearly: 96 Freezes
